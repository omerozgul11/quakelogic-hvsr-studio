# Example datasets — ALL SYNTHETIC

Every file in this folder was generated by `engine/validation/make_examples.py` from
`hvsr_engine.synthetic`. **None of them is a field measurement.** They exist to
demonstrate and test the import wizard, the validation checks and the HVSR workflow.

Model: horizontal components are Gaussian white noise shaped by the transmissibility of a
damped 1-DOF oscillator (resonance f0, peak amplitude A0); the vertical component is
independent white noise of the same variance. The expected HVSR is therefore |H(f)| with
|H(f0)| = A0 (see `docs/hvsr-algorithms.md`, section "Synthetic reference model").
All recordings are 20 minutes at 100 Hz, amplitudes in arbitrary "counts".

| File | Format | f0 | A0 | What it demonstrates |
|---|---|---|---|---|
| `synthetic_site_A_2p5Hz.txt` | tab-delimited, `#` comment header, `time_s` column + N/E/Z | 2.5 Hz | 5 | Delimiter/header detection, seconds time column, sample-rate hint in comments |
| `synthetic_site_B_0p8Hz.csv` | CSV with header, ISO-8601 UTC timestamp column | 0.8 Hz | 4 | Datetime column (rate detected from timestamps); two injected transients at 300 s and 815 s for STA/LTA screening |
| `synthetic_site_C_5Hz.mseed` | MiniSEED, traces `XX.SYNC..HHN/HHE/HHZ` | 5 Hz | 3 | Multi-trace MiniSEED import and channel assignment |
| `synthetic_site_D_split_{N,E,Z}.txt` | three single-column files, no time column | 1.5 Hz | 6 | Separate component files; the sample rate (100 Hz) must be entered because the files carry no timing information; N is 1.6× E (directional / azimuthal analysis) |
| `synthetic_site_E_problems.csv` | CSV with datetime column | 3 Hz | 4 | Validation: 25 NaN samples in N (blocking) and a clipped E component (warning) |

Regenerate with:

```
engine/.venv/bin/python engine/validation/make_examples.py
```
