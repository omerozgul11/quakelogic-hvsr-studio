# Marketing video

`quakelogic-hvsr-studio-overview.mp4` — 2:25, 1920×1080, H.264/AAC. Narrated screen-recorded walkthrough (visible mouse) of the
application with burned-in captions; `quakelogic-hvsr-studio-overview.srt` holds the narration as
subtitles, `quakelogic-hvsr-studio-overview-poster.jpg` is the poster frame.

Produced from real application screens (synthetic demo data) with an offline neural voice
(Kokoro, voice af_heart), captions rendered from `captions.ass`, and a generated background pad.
Regenerate with the scene/narration plan in the session scratchpad (`scenes.json`, `capture.py`,
`compose.py`).
